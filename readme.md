Rock Paper Scissors (C++ Console Game)

A simple console-based implementation of the classic Rock-Paper-Scissors game written in C++. The program allows a user to play against the computer, which generates random moves each round.

Features

- Interactive command-line interface
- Randomized computer choices
- Input validation for user moves
- Score tracking (optional, if implemented)
- Lightweight and beginner-friendly code structure

How It Works

The user selects one of the three options: Rock, Paper, or Scissors. The computer randomly selects its move, and the program determines the winner based on standard game rules:

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

Technologies

- C++ (standard library)
- Console I/O

Purpose

This project is designed as a beginner-level exercise to practice:

- Conditional statements
- Functions and program structure
- Random number generation
- Basic user input handling

Usage

Compile and run the program in a C++ environment:

g++ main.cpp

Notes

This project is intended for learning purposes and can be extended with features such as multiple rounds, scoreboards, or a graphical interface.
